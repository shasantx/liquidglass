# GlassKit v2.0 Implementation Plan

**Goal:** Transform GlassKit into a dual-build publishable npm package (`glasskit-liquid-glass` v2.0.0) exporting the 3-tier optical engine + 10 prop-driven React components + standalone CSS, while fixing website bugs and adding Hero Studio upgrades (install bar, custom background upload, copy config, render-tier switcher, syntax highlighting, theme persistence, SEO & asset optimization).

**Architecture:** Dual-build single repo (`src/glasskit/` compiled via `vite.lib.config.ts` + `tsconfig.lib.json` to `dist-lib/`, while the showcase website in `src/` imports directly from `src/glasskit/` and builds via `vite.config.ts` to `dist/`).

**Spec:** `docs/superpowers/specs/2026-11-22-glasskit-package-and-site-design.md`

---

### Task 1: Core Optical Engine & Primitives (`src/glasskit/core/`, `src/glasskit/primitives/`)
- Upgrade `webglGlassRenderer.ts` with `uOptics[12]` per-element overrides (`refraction`, `blur`, `aberration`, `specular`) and arbitrary `backgroundImage?: string` texture loading/caching (supports remote CORS URLs, local paths, data URLs, and blob URLs, plus WebP wallpaper defaults with fallback).
- Move `liquidGlassEngine.ts` into `src/glasskit/core/` and keep re-export shims at `src/lib/*`.
- Upgrade `GlassSettingsContext.tsx` with `defaultSettings`, `persistTheme`, `renderMode` (`'auto' | 'webgl' | 'svg' | 'css'`), and `localStorage` + `prefers-color-scheme` theme persistence.
- Upgrade `GlassStage.tsx` to accept `scene?`, `backgroundImage?`, `tone?`, `renderMode?`, `style`, and standard div props; render crisp CSS backdrop fallback when `renderMode` is `'svg'` or `'css'` or WebGL2 is unavailable.
- Upgrade `LiquidGlass.tsx` to forward per-element `refraction`, `blur`, `aberration`, `specular`, `bezelWidth`, and `renderMode` into WebGL2 `uOptics`, Tier-2 live SVG `<feDisplacementMap>` (generated via `generateLiquidGlassMaps` + ResizeObserver), and Tier-3 CSS fallback.

### Task 2: 10 Reusable Prop-Driven Library Components & Standalone CSS (`src/glasskit/components/`, `src/glasskit/styles/glasskit.css`, `src/glasskit/index.ts`)
- Extract all component & glass surface CSS (including stage tones and responsive component rules) into `src/glasskit/styles/glasskit.css` and import it from `src/styles/global.css`.
- Build 10 clean, prop-driven React components (zero required icon-library dependency; `ReactNode` icon slots):
  1. `GlassTabBar` (swipeable floating tab bar + optional expandable search)
  2. `GlassSwitch` (droplet-expanding switch)
  3. `GlassSlider` (magnifying drag horizontal slider)
  4. `GlassSegmentedControl` (swipeable segmented selector)
  5. `GlassButton`, `GlassButtonGroup`, `GlassIconButton`
  6. `GlassControlCenter` (connectivity orbs, vertical sliders, focus pill)
  7. `GlassMediaPlayer` (Now Playing glass card)
  8. `GlassContextMenu` (trigger + spring-blooming popover)
  9. `GlassNotificationStack` (collapsible/expandable notification stack)
  10. `GlassAlertSheet` (concentric modal sheet) & `GlassDock` (parabolic magnification dock)
- Refactor all 10 `src/demos/*.tsx` to be clean showcase wrappers using `src/glasskit/`.

### Task 3: Library Build Pipeline (`vite.lib.config.ts`, `tsconfig.lib.json`, `package.json` v2.0.0)
- Configure `vite.lib.config.ts` and `tsconfig.lib.json` to emit `dist-lib/index.js`, `dist-lib/index.cjs`, `dist-lib/index.d.ts`, and `dist-lib/styles.css`.
- Update `package.json` to v2.0.0 with `main`, `module`, `types`, `exports`, `files`, `peerDependencies`, and `build:lib`.

### Task 4: Asset Optimization & SEO (`index.html`, `public/`)
- Optimize `public/logo.jpg` into compact `public/logo-icon.png` + `public/og-preview.jpg` (or WebP) and generate WebP versions of the 4 wallpapers (`tahoe-cobalt.webp`, `sunset-silk.webp`, `midnight-obsidian.webp`, `studio-light.webp`) using Windows-native `.NET`/Node tooling.
- Update `index.html` with full SEO meta description, Open Graph, Twitter Card, canonical/theme tags, and optimized favicon.

### Task 5: Hero Studio Upgrades & Website UX Polish
- `HeroWebGLStage.tsx`: Add 1-click `npm install glasskit-liquid-glass` hero bar + Docs CTA, custom background upload button + drag-and-drop image support, Copy Config / Props button in the optical inspector, and WebGL2 / SVG DOM / CSS live tier preview switcher.
- `CodeBlock.tsx`: Add lightweight zero-dependency syntax highlighting (TSX/JSX, CSS, HTML, GLSL, bash).
- `ComponentStage.tsx`: Improve Copy UX so quick copy indicates/matches active code tab (`Copy HTML` / `Copy React`).
- `DocsSection.tsx` & `App.tsx`: Sync `/docs#<tab>` hash deep-links, update `document.title` per route/tab, update all docs & `componentRegistry.ts` & `README.md` to v2.0.0 npm install usage + accurate `<GlassStage>` API.

### Task 6: Verification, Release Commit, Tag & Push (`v2.0.0`)
- Run `npm run build` and `npm run build:lib`, verify `dist/` and `dist-lib/` outputs and TypeScript declarations.
- Smoke-test the built site in local preview / dev server to verify zero console errors and all interactive flows.
- Commit cleanly, tag `v2.0.0`, and push branch + tag to `origin`.
